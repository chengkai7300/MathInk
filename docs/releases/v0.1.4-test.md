# MathInk v0.1.4-test

支持局域网多设备同步：一台 PC 做服务器，多台 PC / 平板同时加入同一个「房间」，共享画布和识别结果。

## 使用方式

1. **服务器 PC** 启动 MathInk（双击 `MathInk.exe` 或 `start.ps1`）
2. **其他 PC** 浏览器打开 `http://<服务器IP>:8848/`，默认进入 `main` 房间
3. **平板** 扫主机页二维码（二维码自动带房间参数）

多个设备会实时看到：

- 同一块画布上的笔画与书写预览
- 同一份识别结果（任一设备触发识别，所有设备同步显示）
- 在线设备数（主机页右上角「平板 N · 主机 M」）

## 房间

- 默认房间：`main`
- 独立房间：`http://<IP>:8848/?room=team-a`，平板链接同理
- 不同房间的画布、结果、在线状态完全隔离
- 主机页会显示当前房间，二维码自动附带 `room` 参数

## 同步细节

- 识别结果带画布版本号 `rev`；如果识别期间画布又变了，旧结果会被客户端忽略
- 画布比例由房间内第一个平板决定并锁定；其他平板/PC 显示阴影边距，避免互相改比例
- 平板端也会显示其他设备推来的笔画与实时预览

## 防火墙

其他 PC 打不开时，在服务器 PC 上以管理员运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\allow_firewall.ps1
```

或手动：

```powershell
netsh advfirewall firewall add rule name="MathInk 8848" dir=in action=allow protocol=TCP localport=8848
```

## 注意

- 服务以 `0.0.0.0` 监听；同一局域网即可访问
- 无鉴权，只适合可信网络，不要映射到公网
- 识别在服务器 GPU 上串行执行；多设备同时点识别会排队，显示端几乎无开销
- 服务器 IP 探测不准时，启动前设 `MATHINK_LAN_IP=192.168.x.x`
