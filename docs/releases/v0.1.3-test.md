# MathInk v0.1.3-test

新增 **单文件 `MathInk.exe`**，并让 **PC 主机端也能停笔自动识别**。

## 新增：MathInk.exe

- 单文件（约 58 MB），双击即可启动，不再需要 PowerShell 或手动开服务
- 内置：托盘图标、FastAPI/Web 前端、CoMER INT8 模型
- 放在项目根目录时，自动使用旁边的：
  - `models/vlm/` → 高精度 Uni-MuMER 2B
  - `tools/llama/` → llama.cpp 运行时
- 单独拷到其他文件夹也能用 **CoMER（CPU）**；没有 VLM 时界面自动降级
- 关闭：托盘右键「退出 MathInk」或 `MathInk.exe --stop`
- 日志：`logs/launcher.log`

> Windows 可能提示"未知发布者"（未签名），选择"更多信息 → 仍要运行"即可。
> 构建：`powershell -ExecutionPolicy Bypass -File .\build_exe.ps1 -Clean`

## 新增：PC 端自动识别

- 在主机画布上书写时，停笔约 **0.9 秒**自动识别，和 pad 端一致
- 工具栏「自动」开关可关闭；重新识别、清空、切换引擎时取消排队
- 识别期间「重新识别」按钮置灰，避免重复请求

## 验证

- `MathInk.exe` 启动：健康检查 200，托盘 `visible=True`，VLM 1.7 s 内就绪
- 主机端 CDP 画一笔竖线：**未点击按钮**，自动得到 LaTeX 与 42 ms VLM 耗时
- `MathInk.exe --stop`：显存 3939 → 2094 MiB，8848/8849 端口释放
- 单独运行 `dist\MathInk.exe`（无 models/tools）：CoMER 从内置资源加载，页面 200
- 单元测试 6/6 通过

## 已知限制

- exe 未签名，SmartScreen 可能拦截
- VLM 模型（1.5 GB）和 llama.cpp 运行时不打进 exe，需放在 exe 同目录
- 仅 Windows
